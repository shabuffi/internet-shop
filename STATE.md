# Состояние сайта — ТД «ИНЖЕНЕР» (снимок на 29.06.2026)

Этот файл — **снимок текущей функциональности** (что есть / чего нет / открытые вопросы).
Журнал изменений по спринтам — в [SPRINTS.md](SPRINTS.md); архитектура и команды — в [CLAUDE.md](CLAUDE.md).

## Что это
Интернет-магазин (опт/розница) с **МойСклад** как мастер-системой каталога.
Каталог/остатки/картинки приходят из МойСклад по **CommerceML**, заказы уходят обратно.
Пароль аккаунта МойСклад не используется — только выдуманная пара логин/пароль обмена.

## Стек
- **Backend:** Python 3.12 / FastAPI (порт 8000) + Celery worker/beat
- **Frontend:** Next.js 15 (App Router, SSR, порт 3000)
- **БД:** PostgreSQL 16 · **Брокер:** Redis 7 · **Прокси:** nginx
- Всё в Docker (7 сервисов), прод: `139.100.226.168`, `/opt/internet-shop`, деплой `git pull && ./deploy.sh`

## Что РЕАЛИЗОВАНО

### Витрина (покупатель)
- Главная: hero, карта 6 областей доставки, плитки 8 групп категорий, бегущая строка регионов, «О компании», контакты.
- Каталог `/catalog`: список/плитки, фильтр по категориям (в т.ч. группы), сортировка, поиск (в т.ч. при неправильной раскладке EN↔RU), колонка «Остаток».
- Карточка товара `/products/[id]`: галерея, описание, характеристики, выбор количества, добавление в корзину.
- Корзина `/cart` и оформление `/checkout` → `/checkout/success`. **Минимальный заказ 5 000 ₽** (показ + блокировка на фронте и бэке).
- Картинки товара отдаёт бэк `/api/v1/products/{id}/image` из тома `media_storage`.

### Заказы
- `POST /api/v1/orders` — создание заказа: запись в БД, списание остатка, уведомление владельцу (Телеграм/ВК).
- Выгрузка в МойСклад: МойСклад сам забирает неэкспортированные заказы (`type=sale&mode=query`), помечаем `exported_at`.

### Обмен CommerceML `/api/v1/1c/exchange`
- Каталог вниз: checkauth/init → import.xml + offers.xml + файлы картинок → `upsert_catalog()`.
- Заказы вверх: query/success.
- Состояние обмена — в Redis (переживает рестарт), картинки — на диске.

### Админка `/admin` (JWT в httpOnly-куке + bcrypt)
- Вход `/admin/login`; разделы: товары, заказы, синхронизация (журнал), настройки магазина, dev.
- В товарах: загрузка/удаление картинок вручную (флаг `images_manual` защищает их от перезатирания обменом).

### Формы
- `LeadForm` — заявка «уточнить условия оптовой поставки» → `/api/v1/leads` (уведомление владельцу). Задел под будущие кабинеты.

### Модели БД
`product.py` (Product, Category, SyncLog) · `order.py` (Order, OrderItem) · `lead.py` (Lead) · `admin.py` (админ-пользователь).

## Чего ПОКА НЕТ (важно для нового ТЗ)
- **Нет личного кабинета покупателя и регистрации** — авторизация есть только у админа.
- **Нет наценки/персональных скидок** — цена отдаётся как пришла из МойСклад, одинаковая для всех.
- **Нет выбора способа доставки** при оформлении (самовывоз / транспорт ТД / ТК).
- **Нет передачи данных заказчика и способа доставки** в МойСклад из кабинета.
- **Нет публичной оферты / согласия на обработку ПД** (152-ФЗ).

## Недавние фиксы (запушены, ждут деплоя)
- Удалённые в МойСклад фото теперь чистятся на сайте (раньше «зависали»).
- Заменённое фото больше не кэшируется до суток (ETag + ревалидация).
- Лого перекрашено под цвет сайта (#003399/#E02424); favicon — эмблема на прозрачном фоне.

## Открытые вопросы / эксплуатация
- **Синхронизация встала с 22.06** — причина на стороне МойСклад (вероятно, закончился пробный период/тариф: Онлайн-торговля доступна только на платном тарифе). Сервер и магазин проверены — здоровы. Нужна проверка/оплата тарифа МойСклад владельцем аккаунта.
- Наполнение МойСклад (описания/фото/характеристики) — на стороне заказчика; без данных карточки минималистичны.
