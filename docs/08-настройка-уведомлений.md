# 08. Настройка уведомлений о заказах (для владельца)

Когда покупатель оформляет заказ, владелец получает оповещение. Каналов три, можно
включить любой (или несколько). Все настраиваются в **админке → Настройки → «Уведомления
о заказах»**. Пустые поля просто игнорируются.

- **Telegram** — самый простой, рекомендуем начать с него.
- **ВКонтакте** — чуть сложнее (нужно сообщество).
- **Email** — письмо на вашу почту (требует данных почтового сервера).

После заполнения полей нажмите **«Сохранить настройки»** и оформите тестовый заказ —
проверить, что оповещение пришло.

---

## 1. Telegram (рекомендуется)

Нужно получить две вещи: **токен бота** и **chat_id** (куда слать).

### Шаг 1. Создать бота и получить токен
1. Откройте Telegram, в поиске найдите **@BotFather** (с синей галочкой), напишите ему `/start`.
2. Отправьте команду `/newbot`.
3. BotFather спросит **имя бота** (любое, например «Мой Магазин Заказы») — отправьте.
4. Затем спросит **username бота** — он должен заканчиваться на `bot` (например `moymagazin_orders_bot`). Если занят — придумайте другой.
5. В ответ BotFather пришлёт **токен** — длинную строку вида
   `7123456789:AAH...xYz`. Это и есть **токен бота** → впишите в поле
   «Telegram — токен бота».

### Шаг 2. Узнать свой chat_id
1. Найдите своего бота по username (из шага 4) и нажмите **Start** (это обязательно —
   иначе бот не сможет вам писать).
2. В поиске найдите **@userinfobot**, напишите ему `/start`.
3. Он пришлёт ваш **Id** (число, например `123456789`). Это ваш **chat_id** →
   впишите в поле «Telegram — chat_id».

Готово. Сохраните настройки — оповещения о заказах будут приходить вам в Telegram.

> Хотите получать заказы в **группу** (например, с менеджерами)? Добавьте бота в группу,
> и chat_id будет id группы (отрицательное число). Узнать его проще через @userinfobot,
> добавленного в ту же группу. Для начала проще — личные сообщения.

## 2. ВКонтакте

Бот ВК работает **от имени сообщества** (группы/паблика). Нужно: **сообщество**, **ключ
доступа** и **peer_id** (ваш id ВК).

### Шаг 1. Создать сообщество (если ещё нет)
1. ВКонтакте → слева **«Сообщества»** → **«Создать сообщество»**.
2. Выберите любой тип (например «Бизнес»), назовите (например «Мой Магазин»), создайте.

### Шаг 2. Включить сообщения сообщества
1. В сообществе: **«Управление»** → **«Сообщения»** → переключатель **«Сообщения
   сообщества»** → **Включены**.

### Шаг 3. Получить ключ доступа
1. **«Управление»** → **«Настройки»** → **«Работа с API»** → вкладка **«Ключи доступа»**.
2. **«Создать ключ»** → отметьте права **«Управление сообществом»** и **«Сообщения
   сообщества»** → создать.
3. Скопируйте ключ (длинная строка вида `vk1.a.AbC...`) → впишите в поле
   «ВК — ключ доступа сообщества».

### Шаг 4. Разрешить боту писать вам и узнать peer_id
1. **Напишите своему сообществу любое сообщение** от своего личного аккаунта (зайдите в
   сообщество → «Написать сообщение»). Без этого ВК запрещает боту писать вам первым.
2. Узнайте свой **числовой id ВК**: откройте свою страницу, если в адресе `vk.com/id123456`
   — это и есть число. Если там короткое имя (`vk.com/ivan`) — откройте любой сервис
   «узнать id ВКонтакте» (например regvk.com/id) и вставьте ссылку на свою страницу.
3. Это число → впишите в поле **«ВК — peer_id получателя»**.

Сохраните. Теперь о новых заказах сообщество будет писать вам в личные сообщения ВК.

## 3. Email (письмо на вашу почту)

Чтобы отправлять письма, магазину нужен доступ к **почтовому серверу (SMTP)** какого-то
почтового ящика. Удобно завести/использовать отдельную почту магазина.

В админке два места:
- **«Email владельца»** (в блоке «Уведомления») — адрес, **куда** вам приходят письма о заказах.
- **«Почтовый сервер (SMTP)»** — данные ящика, **через который** письма отправляются.

### Пример: Яндекс.Почта
1. Заведите/откройте ящик на **yandex.ru** (например `moymagazin@yandex.ru`).
2. Создайте **пароль приложения** (обычный пароль от почты не подойдёт):
   Яндекс ID → **«Безопасность»** → **«Пароли приложений»** → **«Создать»** → выберите
   «Почта» → задайте имя → получите пароль (16 символов). Скопируйте его.
3. В админке → «Почтовый сервер (SMTP)» заполните:
   - **SMTP-сервер:** `smtp.yandex.ru`
   - **Порт:** `587`
   - **Логин:** ваш адрес, например `moymagazin@yandex.ru`
   - **Пароль SMTP:** пароль приложения из шага 2
   - **Адрес «От кого»:** можно оставить пустым (= логин)
4. В поле **«Email владельца»** впишите, куда хотите получать заказы (можно тот же адрес).

### Другие почты (параметры SMTP)
- **Mail.ru:** сервер `smtp.mail.ru`, порт `587`; тоже нужен **пароль для внешних
  приложений** (Настройки → Безопасность → Пароли для внешних приложений).
- **Gmail:** сервер `smtp.gmail.com`, порт `587`; нужен **App Password** (включить
  двухфакторную аутентификацию → App passwords).

Сохраните настройки и оформите тестовый заказ — письмо должно прийти на «Email владельца».

---

## Проверка

После настройки любого канала: оформите тестовый заказ на сайте и убедитесь, что
оповещение пришло. Если нет — проверьте, что:
- поля сохранены (нажата кнопка «Сохранить настройки»);
- для Email — заполнены **оба** блока (Email владельца + Почтовый сервер), и пароль —
  именно «для приложений», а не обычный;
- для ВК — вы **написали сообществу первым**;
- для Telegram — вы нажали **Start** у своего бота.
